      Deployment steps used for this site

      1. Wrote the site with HTML, CSS and JavaScript.
      2. Pushed the project to a GitHub repository.
      3. Connected GitHub to Netlify and imported the repository.
      4. Set the build settings: no build command, publish directory .
      5. Deployed, then renamed the site under Site configuration.
      6. Verified the live URL.
